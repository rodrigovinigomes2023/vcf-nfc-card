## Checado e sem problema

- Nenhum dado pessoal vai para log; perfis ficam guardados só no celular (armazenamento privado do app).
- O app em si não usa a internet. Na página `/v`, os dados vão depois do `#`, que **nunca chega ao servidor**.
- Página web sem XSS: todo dado do link entra como texto; links têm prefixo fixo (`tel:`, `mailto:`, `https://`).
- Serviço NFC protegido por `BIND_NFC_SERVICE` (só o sistema se liga a ele); leitura de arquivos NFC com limites corretos, fora o A1.
- Nenhuma chave, `.jks` ou `.env` no repositório; `.gitignore` cobre todos.
- Licenças corretas: app GPL-3.0, QR Code MIT, fontes Inter OFL.
